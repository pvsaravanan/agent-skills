# web3d

Seven skills for 3D and rich-motion web work: `threejs-webgl`, `react-three-fiber`, `lottie-animations`, `rive-interactive`, `spline-interactive`, `blender-web-pipeline`, `barba-js`.

Install: `/plugin install web3d --marketplace pvsaravanan/agent-skills`

Source: [freshtechbro/claudedesignskills](https://github.com/freshtechbro/claudedesignskills). Its LICENSE says MIT (copy in `LICENSE`), though its plugin manifests say Apache-2.0. The upstream `react-three-fiber/scripts/component_generator.py` does not compile and is omitted.
